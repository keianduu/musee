# Musee Prototype

This directory is the exploratory UI/UX workspace.

## Entry points

- `index.html` — Home
- `exhibition.html` — Exhibition detail scaffold
- `museum.html` — Museum detail scaffold
- `artist.html` — Artist detail scaffold
- `map.html` — Map prototype
- `saved.html` — Saved scaffold
- `my-art.html` — My Art / ArtWall scaffold

## Rules

- Use stable filenames.
- Do not create `v2`, `final`, `latest` copies. Use Git history.
- Prototype changes do not automatically become Notion specifications.
- When a direction is explicitly approved, update the relevant Notion specification / Decision.
- Production code will live under `src/` later.
